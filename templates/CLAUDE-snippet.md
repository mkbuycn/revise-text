## revise-text
Files matching `targets` in .revise-text/config.json (here: `tasks/*/instruction.md`) are revise-text
targets. When you create or change one, use the revise-text skill (Mode A) before you finish: write it with
the skill's writing rules, save its spec, run it and verify it. Never hand-edit a revised region; to change
one, update the spec and your draft and run revise-text again (verify removed the region's markers, so add them
back or select the region by heading). In other files, revise only what the user asks for.
